# Compass

## Cursor Cloud specific instructions

Next.js 16 app with Turbopack, TypeScript, Tailwind CSS 4, and ESLint (flat config).

### Key commands

| Task | Command |
|------|---------|
| Dev server (Turbopack) | `pnpm dev` |
| Production build | `pnpm build` |
| Start production server | `pnpm start` |
| Lint (ESLint) | `pnpm lint` |

### Non-obvious notes

- **Turbopack is the default bundler** for both `next dev` and `next build` in Next.js 16. No extra flags needed.
- The dev server supports HMR out of the box; file saves in `src/` are reflected instantly.
- ESLint uses the flat config format (`eslint.config.mjs`), not `.eslintrc`.
- Tailwind CSS 4 uses `@tailwindcss/postcss` (no `tailwind.config.js` needed; config is via CSS).
- `pnpm-workspace.yaml` exists but the project is not a monorepo; it was generated by `create-next-app`.
- No test framework is installed yet. Add one (e.g. Jest, Vitest, Playwright) when tests are needed.
